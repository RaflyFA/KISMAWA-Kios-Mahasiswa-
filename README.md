# KISMAWA — Kios Mahasiswa (KOPMA UNSIL)

Landing page katalog produk KISMAWA dari KOPMA Universitas Siliwangi (UNSIL).

## Tech Stack
- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **UI & Styling**: Tailwind CSS v4, Lucide Icons, Google Fonts (Outfit & Quicksand)
- **Deployment**: Vercel

## Fitur
- 🛍️ Katalog Produk Real (Buket & Hampers)
- 📲 Integrasi Pemesanan Otomatis via WhatsApp (`+62 812-2066-2230`)
- 🖼️ Hero Banner Carousel Otomatis
- 🕒 Jam Operasional & Alamat KOPMA UNSIL
- 📱 Desain Mobile-First & Responsif

## Cara Menjalankan Project

```bash
# Install dependencies
npm install

# Menjalankan server development
npm run dev
```
